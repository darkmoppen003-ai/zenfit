## 3. Architecture (do not violate)

- `modules/core/store.js` — single source of truth. Same storage keys as V1 (`zenfit_v1` etc.), `DATA_VERSION = 11`. `update(fn, {silent})` + `save()` (debounced) + `notify()`.
- `modules/core/selectors.js` — ONLY place for derived data. V1 shapes: `nutrients{}`, `calories`, `duration`, `completedDates`.
- `modules/core/router.js` — `SCREENS` registry (V1 emoji icons + labels; router auto-injects header). Bottom dock = SVG `DOCK_ICONS`. No top nav (V1 removed it). Hidden `admin` route.
- `modules/core/ui.js` — `showNotif(msg, icon)` V1 API, `awardXP()`, `applyBackgroundConfig()`, 6-mode particles, WebAudio SFX, `ICONS` SVG set.
- `modules/core/achievements.js` — 43 ACHIEVEMENTS, V1-exact check (direct XP, `{id, ts}`, trophy toast). Boot check at 200ms in `app.js`.
- `modules/core/nutrition-parse.js` — V1 engine verbatim (ALIASES, FOOD_UNIT, resolveQty, parseFood comma-split, gradeFood formula, recalcFood) + OFF + Gemini worker tiers. Uses `window.INGR_DB` global.
- `modules/core/peer.js` + `cloud.js` — PeerJS P2P (handshake/chat/challenges) + Supabase global board. `notify.js` — local reminders. `secrets.js` — admin SHA-256 (plaintext ONLY in gitignored `admin.env`).
- `css/tokens.css` — ONLY file with color/font values. Everything else `var(--*)`.
- Rules: sanitize all inputs, local dates via `getTodayStr()`/`today()` (never UTC slice), no commented-out code (delete dead code), no `void` hacks, V1 formulas verbatim (rank `floor(level/8)`, XP `100·level^1.5`, +30/meal, +5 water/+50 goal, habits 20/40/70, tasks 30/70/130/220, workout 15/8).

## 6. Gotchas learned

- Headless Chromium lacks emoji fonts + blocks external net: twemoji shows fallback, OFF/Gemini fail gracefully. Not app bugs.
- `localStorage` seed via `ZF.update()` needs flush wait; direct-storage seeding needs reload.
- Level-up overlays intercept test clicks → dismiss between steps.
- `renderActive` catches render throws → "Couldn't load X" + console.warn (assert on that text in smoke tests).
- Mood buttons need twemoji CSS (was missing once → 512px blowup). Always keep img sizing CSS with remote images.
- V1 quirks mirrored intentionally: weight once/day no-XP, rest-day one-way max-3, task overdue penalties, achievement direct-XP (no recursion), boot achievement check, changelog per build, char-card daily collapse reset.
