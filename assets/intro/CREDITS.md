### Rights status — read before publishing

The licence of this artwork is **unverified**. wallhaven.cc hosts it as
user-uploaded content, states `source not provided`, and explicitly keeps
ownership with the original owners. The image is an anime character
illustration (Kaneki Ken, *Tokyo Ghoul*), i.e. derivative work of
third-party copyrighted character art. wallhaven's own terms do not grant
redistribution rights for it.

Bundled here because the Hunter's Code screen was specified to use this
exact image as its principal visual reference. **Before a public
distribution of ZenFit, the maintainer must clear the licence** (replace
the asset with a self-made / clearly licensed one, or obtain permission).
No attribution requirement could be determined, because no author or
licence is stated for the upload; the source URL is preserved above for
traceability.

The artwork is bundled locally on purpose (not hotlinked) so the first-run
rules screen loads offline in the PWA. It is listed in `sw.js`
`STATIC_ASSETS` so the service worker caches it.
